# Nutrition and Diet Plan - Python Project

## About
This is a simple beginner-level Python project that calculates BMI, estimates daily calorie needs, and displays a basic diet plan according to the user's goal.

## Requirements
- Python 3
- No external Python libraries are required.

## Main Features
- Takes basic user information
- Calculates BMI
- Shows BMI category
- Estimates daily calorie requirements
- Allows the user to select a goal
- Displays a simple diet plan
- Displays basic nutrition tips

## Files
- `nutrition_diet_plan.py` - Main Python program

## Note
This project is intended for educational purposes. The diet suggestions are general examples and are not a substitute for advice from a qualified healthcare professional.
