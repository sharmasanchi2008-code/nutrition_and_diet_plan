# Project Statement

## Project Title

**Nutrition and Diet Plan**

## 1. Problem Statement

Many people find it difficult to organize basic information about their body measurements, estimated calorie requirements and daily meal choices in one simple place.

The purpose of this project is to develop a beginner-friendly Python program that accepts basic user information and provides simple nutrition-related calculations and a basic diet plan.

The project focuses on demonstrating Python programming concepts through a practical problem rather than creating a professional medical or nutritional system.

## 2. Scope of the Project

The project covers the following activities:

- Taking basic user information as input.
- Calculating Body Mass Index (BMI).
- Displaying a basic BMI category.
- Estimating daily calorie requirements using a simple BMR-based calculation.
- Taking the user's physical activity level.
- Allowing the user to select a diet goal.
- Displaying a basic meal plan for the selected goal.
- Displaying general nutrition tips.

### Included

- Command-line interaction.
- Basic calculations.
- Simple decision-making.
- Predefined diet-plan information.
- Input and output handling.

### Not Included

- Medical diagnosis.
- Personalized medical nutrition advice.
- Online services or APIs.
- Database storage.
- User accounts or authentication.
- Graphical user interface.

The project is intentionally kept simple because it is a beginner-level Python academic project.

## 3. Target Users

The intended users are:

1. **Students** who want to understand basic nutrition calculations while learning Python programming.
2. **General users** who want to view simple BMI and calorie estimates.
3. **Beginners learning Python** who want to see how functions, conditions, dictionaries and user input can be combined in a practical project.

The program is not intended to be used as a professional medical or nutritional assessment tool.

## 4. High-Level Features

### Feature 1: User Information

The program accepts:

- Name
- Age
- Gender
- Weight
- Height

### Feature 2: BMI Calculation

The program calculates BMI from the user's weight and height and displays a basic BMI category.

### Feature 3: Calorie Estimation

The program estimates daily calorie requirements using age, gender, weight, height and activity level.

### Feature 4: Activity Selection

The user can select one of four activity levels:

1. Little or no exercise
2. Light exercise
3. Moderate exercise
4. Heavy exercise

### Feature 5: Diet Plan

The user can select:

1. Weight Loss
2. Maintain Weight
3. Weight Gain

The program then displays breakfast, lunch, snack and dinner suggestions.

### Feature 6: Nutrition Tips

The program displays basic tips related to water intake, fruits and vegetables, protein, junk food, sleep and physical activity.

## 5. Expected Outcome

The expected outcome is a working Python command-line application that demonstrates a logical workflow from user input to calculations and diet-plan output.

The project should also demonstrate the student's understanding of basic Python programming concepts.

## 6. Project Limitation

The results generated by the program are estimates and general examples. They should not be considered professional medical or nutritional advice.
